# RefAs-Character / Sculpt Studio Lite

**3D Character Sculpting & Reference Alignment**  
가벼운 단일 HTML 기반 캐릭터 베이스 메시 조형·레퍼런스 정합 워크스페이스입니다. 데스크톱과 모바일 브라우저에서 실행할 수 있으며, 브라우저 안에서 대략적인 형태를 수정한 뒤 OBJ와 편집 세션 JSON을 에이전트나 별도 3D 제작 파이프라인에 전달하는 용도로 설계되었습니다.

> **Status:** Lite / v5.3.1 · standalone HTML · experimental character-sculpt workflow  
> **Run:** [index.html](./index.html) 파일을 다운로드해 최신 브라우저에서 엽니다. 별도 MakeHuman 설치는 필요하지 않습니다.

## Why this exists — agent 작업의 토큰과 시행착오 줄이기

AI 에이전트에게 MakeHuman을 실행하고, 원하는 외형을 문장만으로 해석해 여러 차례 모델링·관찰·수정하게 하면 반복적인 도구 호출, 추정, 재조형에 컨텍스트와 토큰이 소모될 수 있습니다.

이 도구의 목적은 **사람이 레퍼런스를 보며 몇 가지 특징을 직접 수정하고, 그 결과를 에이전트의 시작점으로 넘기는 것**입니다.

1. 레퍼런스 이미지를 등록하고 정면·측면 등 여러 시점에서 기본 메시와 비교합니다.
2. 브러시 및 형상 파라미터로 **조금이라도 목표에 가까운** 두상·얼굴 윤곽을 만듭니다.
3. **OBJ(실제 형상)** 와 **JSON(편집 상태)** 을 저장합니다.
4. 해당 파일과 원본 레퍼런스를 에이전트에게 제공해 Blender, RefAs-Character, ym3d 등 후속 환경에서 정밀화하도록 합니다.

이렇게 하면 에이전트가 처음부터 모든 형상을 추측하거나 MakeHuman 인터페이스를 반복 조작할 필요를 **줄일 가능성**이 있습니다. **토큰 절감은 목표/워크플로에 따른 기대효과이며, 이 저장소에서 정량적으로 벤치마크하거나 보장한 결과는 아닙니다.** 본 프로젝트는 MakeHuman을 대체하는 완전한 캐릭터 생성기가 아니라, 경량 **사전 조형·정합 도구**입니다.

## Features

| 구분 | 지원 내용 |
| --- | --- |
| 실행 | 단일 HTML 파일, 브라우저 기반 오프라인 작업, 내장 기본 메시 |
| 뷰 | 메인 3D 뷰와 정면 / 3/4 / 측면 / 후면 다중 뷰, 회전·이동·확대·초기화 |
| 레퍼런스 | 뷰별 이미지 등록·교체, Overlay / Split 비교, 이미지 변환·정합 보조 |
| 조형 | 이동(Push/Move), 쌓기(Build), 깎기(Carve) 브러시, 반경·강도 조절, X축 대칭 |
| 형태 보정 | 얼굴·두상 관련 파라미터 기반 변형과 카메라/레퍼런스 비교 |
| 안전성 | 뒤집힌 면·퇴화·면적비·이동량 검사, 편집 거부 사유 토스트, **안전 제한 해제** 선택 |
| 편집 UX | Undo / Redo, 브러시 커서, 아이콘 중심 도구, 사용 가이드·단축키 |
| 모바일 | 단일 뷰 탭, 카메라/조형 모드 분리, 멀티터치 이동·핀치 확대, 반응형 컨트롤 |
| 교환 | OBJ 모델, JSON 작업 세션, PNG 화면 캡처 |

> 실제 기능의 상세 사용법과 단축키는 앱의 **가이드** 버튼에서 확인할 수 있습니다.

## Quick start

1. 저장소의 **[index.html](./index.html)** 을 다운로드합니다.
2. 데스크톱 또는 모바일 브라우저로 엽니다.
3. 기본 형상을 회전하며 확인하고, 원하는 시점에 레퍼런스를 업로드합니다.
4. 이미지와 메시의 배율·위치를 조정한 후 Overlay / Split으로 비교합니다.
5. 필요한 부분만 조금씩 조형하고 정면·측면·3/4에서 다시 확인합니다.
6. **OBJ** 와 **JSON** 을 함께 저장합니다. 에이전트 작업에 사용할 때는 원본 레퍼런스도 같이 전달하세요.

**에이전트에 전달할 때의 예시 요청**

> 첨부된 OBJ를 시작 메시로 사용하고, 레퍼런스 정면·측면과 비교해 두상과 얼굴 비율을 개선해 주세요. JSON은 편집 이력/상태 참고용입니다. 관찰 가능한 차이와 추정 형상을 구분하고, 수정 전후를 같은 카메라에서 검증해 주세요. 기존 메시를 무조건 폐기하고 처음부터 재생성하지 마세요.

## Current limitations

- **자동 이미지 → 3D 복원은 지원하지 않습니다.** 레퍼런스 정합·랜드마크는 관찰과 수동 조정을 돕는 기능이며, 사진의 정확한 3D 해부학을 복구한다는 의미가 아닙니다.
- 베이스 메시를 변형하는 **Lite 조형기**입니다. 전문 DCC 도구 수준의 세밀한 스컬프, 리토폴로지, UV 제작, 텍스처/헤어/의상 저작, 완전한 표정 리깅·애니메이션을 제공하지 않습니다.
- 과도한 브러시 변형에서는 삼각형이 늘어나거나 뒤집힐 수 있습니다. **안전 제한 해제**는 작업을 허용할 뿐 품질을 보장하지 않습니다.
- 정확한 닮음(likeness), 해부학적 타당성, 제작용 메시 품질, 레퍼런스와의 수치적 일치를 자동 보증하지 않습니다.
- OBJ 내보내기는 **후속 편집을 위한 후보 메시**입니다. 실제 파이프라인 투입 전에는 토폴로지·노멀·자체교차·스케일 등을 점검하세요.
- 모바일 및 태블릿의 GPU·메모리 성능은 기기와 브라우저에 따라 다릅니다. iOS/Android 전 기종에서의 장시간 조형 성능과 스타일러스 압력 지원은 검증되지 않았습니다.
- 현재 작업 파일은 JSON/OBJ를 사용합니다. MakeHuman의 네이티브 편집 프로젝트(.mhm)를 직접 여닫는 도구는 아닙니다.

## Project direction

Lite는 **빠른 형태 초안·레퍼런스 비교·에이전트 핸드오프**에 집중합니다. 보다 높은 유사도, 다중 시점 검증, 해부학 재설계, 고품질 리깅·재질 및 완성형 캐릭터 제작은 별도의 본격적인 3D 제작 파이프라인에서 처리하는 방향을 권장합니다.
