04 · 레퍼런스 비교와 정합

도구사용법
레퍼런스 업로드4면 뷰 하단의 ＋ 또는 이미지 ↥를 누르거나 해당 패널에 이미지를 드롭합니다. PNG·JPG·WEBP·GIF·AVIF, 20MB 이하.
Overlay / Split / 윤곽 / Clay·Wire뷰 하단 비교 모드를 전환하여 사진·메시를 겹치거나 분할 비교합니다. 윤곽 비교나 메시 전용 화면도 가능합니다.
REF 이동 · 정합 설정REF 이동을 켜고 좌클릭 드래그로 사진을 이동합니다. 정합 설정에서 사진의 X/Y·배율·회전·투명도를 조절합니다.
기준점 정합점 정합 → 기준점 선택 → REF 점 클릭 → 동일 위치의 3D 점 클릭. 3쌍 이상 입력 후 카메라 맞춤을 실행합니다.
뷰 추가＋ 뷰 추가로 커스텀 카메라 패널을 추가합니다. 기본 4면 이외의 참조 이미지도 활용할 수 있습니다.
레퍼런스 업로드만으로 카메라가 자동 정합되지는 않습니다. 기준점 정합은 카메라 각도·배율·이동을 보정하며, 3D 메시 형상 자체는 변경하지 않습니다.

05 · 조형 안전성과 저장

편집 · 검증

왼쪽의 해부학적 파라미터로 부위별 치수를 조절할 수 있습니다. 대칭은 X축 양쪽에 브러시를 적용합니다. BEFORE는 원본을 임시로 보여주며 그동안 브러시가 잠깁니다. 변형 히트맵은 원본 대비 이동량을 표시합니다.

안전 제한이 켜져 있을 때는 뒤집힌 면·퇴화 면이 없어야 하고, 최소 면적비 35% 이상, 원본 대비 최대 이동 22mm 이하여야 합니다. 거부되면 이유가 토스트로 표시됩니다.

저장 · 복원

상단 다운로드 아이콘은 편집한 3D 모델을 OBJ로 내보냅니다. 상단 기록 아이콘을 열어 상태 JSON 저장, JSON 불러오기, PNG 캡처를 이용할 수 있습니다.

모두 0으로는 형상 파라미터를 초기화하고, 획 제거는 브러시 작업을 삭제합니다. 샘플 초기화는 기본 샘플 상태로 되돌립니다. 중요한 작업 전에는 JSON 저장을 권장합니다.

안전 제한 해제: 검증 결과에 의한 변형 거부를 우회합니다. 심한 메시 찢김·뒤집힘이 발생할 수 있으며, 무결성 검사가 통과된다는 뜻은 아닙니다. 기본 상태에서는 제한이 활성화됩니다.
